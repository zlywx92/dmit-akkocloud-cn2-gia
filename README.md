## 第二关：线路是不是真的三网 CN2 GIA

DMIT Pro 的硬指标是三网 CN2 GIA，自有 40Gbps CN2 GIA 带宽，不靠转售。AkkoCloud 官网对圣何塞和伦敦都标注 CN2 GIA，圣何塞页面提供 Looking Glass 测试入口和测试 IP，可以自己 ping 一遍。

伦敦节点有一份第三方实测（NodeQuality，2025 年 6 月）：回程电信联通走 CTG/CN2 GIA、移动走 CMIN2；去程移动走 CMIN2、联通走 10099、电信走 CN2/CTG GIA。DMIT Pro 按官方描述是回程三网 CN2 GIA、电信联通去程 CN2 GIA、移动去程 CMI，两家在移动这一段的处理不一样。

同一份实测里还有个数字值得看：iPerf3 单线程 TCP 回中国大约 100Mbps，标称 500Mbps 的带宽单线程跑不满。跨境单线程受路由和拥塞影响本来就常见，但你如果指望单线程吃满带宽，这个结果要先知道。

圣何塞这条线目前只有官网的测试入口，没找到同等口径的第三方晚高峰路由实测，我不替它下结论。买之前拿 Looking Glass 和测试 IP 自己跑一遍，比看任何评测都直接。

## 第三关：IP 是不是原生

DMIT 的原生 IP 是它相对搬瓦工的一个明确优势。AkkoCloud 圣何塞页面写明"分配 38 段美国原生 IP 或提供 DNS 解锁美国地区流媒体服务（Netflix、Disney+ 等）"，需要美国 IP 做平台验证或解锁流媒体的，这条线对得上。

伦敦那台机器在第三方检测里的 IP 质量标注是 US broadcast IP，也就是美国广播 IP，不是英国本地原生。要英国本地 IP 的，伦敦这条线不合适。

## DMIT 这几个套餐不值得等

### 圣何塞 SJC 已经停售

2023 年 4 月起，DMIT 的圣何塞机房改为普通国际直连，电信走 163 骨干、联通走 4837 或普通骨干、移动走 CMI，没有大陆专项优化，相关套餐已经停售。现在再去翻 SJC 的购买页没有意义。

### T1 系列不做大陆优化

T1 是国际线路，官方定位是海外建站、CDN 节点、开发测试。拿它回国用，线路质量不如 EB 和 Pro，价格再低也不对症。

### Pro 缺货时，EB 能顶一部分

EB 的回程是 CMIN2，移动用户体验不错，价格通常也比同档 Pro 友好。要注意 Pro 以外的高端优化线路在网络攻击或成本上升时存在切换路由的可能，对 CN2 GIA 有强需求、不接受线路变化的，只能等 Pro 补货。
